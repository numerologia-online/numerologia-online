# Детский разбор дня - база текстов

Расчёт полностью повторяет **действующую формулу** взрослого «Личного разбора дня». Код формулы: `child/child-day-engine.js`. Взрослый раздел **не изменять**.

## Куда писать

Папка `child/data/day/entries/`: 22 файла, `child-day-01.json` ... `child-day-22.json`.

Каждый файл содержит **31 персональную позицию** (ключи `"1"` ... `"31"`). Итого **22 × 31 = 682 самостоятельных прогноза**. Число 31 здесь НЕ календарный день месяца. Не путать.

В каждой записи:
- `text` - основной авторский прогноз ребёнка, раскрывающий комбинацию двух чисел без перечисления цифр для читателя
- `todayNeed` - список 2-4 практических советов **что сегодня важно поддержать**
- `todayAvoid` - список 2-4 предостережений **чего сегодня лучше избегать**
- `parentAttention` - список 1-3 наблюдений/сигналов, на которые родителю стоит обратить внимание, в том числе разговоры, границы, поддержку, конфликты, потребность в отдыхе
- `ageHints.young` - необязательная уточняющая фраза для детей до 6 лет
- `ageHints.school` - необязательная уточняющая фраза для 6-11 лет
- `ageHints.teen` - необязательная уточняющая фраза для 12-17 лет
- `status` - **draft**, пока не утверждено, затем **ready**, когда вся авторская запись утверждена

Пример формы (пример структуры, НЕ трактовка):
```json
"12": {
  "status": "draft",
  "text": "",
  "todayNeed": [],
  "todayAvoid": [],
  "parentAttention": [],
  "ageHints": { "young": "", "school": "", "teen": "" }
}
```

### Схема работы

1. По дате рождения и выбранной дате считаются `energy` (1..22) и `personalNumber` (1..31).
2. Загружается только ОДИН JSON нужной энергии. Например, энергия 9 → `child-day-09.json`, персональная позиция 12 → `entries["12"]`.
3. Если `status === "ready"` и основной `text` не пустой, выводится авторский текст и все заполненные рекомендации, включая возрастную подсказку, если есть.
4. Иначе сохраняется действующий короткий детский прогноз из `child/data/day.json`, чтобы незаполненная база ничего не сломала.
5. Возраст влияет ТОЛЬКО на стиль и дополнительные возрастные подсказки, но НЕ на энергию дня.

Нумерологическую формулу без согласования **не менять**. Число 22 - шкала энергий с повторным вычитанием 22; позиция до 31 - отдельная шкала. Личные год, месяц и день - цикл 1..9. Мастер-числа 11, 22, 33 при числе жизни сохраняются.

### Стиль будущих трактовок

Один основной живой абзац, без канцелярита и слишком младенческих образов. Подходит школьникам и подросткам, с необязательными подсказками по возрасту. К ребёнку - с уважением, к родителям - с теплом и конкретикой. Больше внимания общению, чувствам, учёбе, активности и восстановлению. Предостережения про общение, спешку, давление и отсутствие поддержки, без запугивания, диагнозов и обещаний неизбежных событий.

### Последующая работа

Тексты согласовываются **по 10 индивидуальных связок**, только после одобрения ставится `ready`. Сложные расчёты остаются в JS, авторские слова только в JSON. Календарь детских важных дней потребует отдельного согласования детских категорий; взрослые категории «для денег», «покупки» и другие не копировать детям напрямую.
