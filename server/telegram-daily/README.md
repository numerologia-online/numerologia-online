# Утренняя автоматическая Telegram-рассылка

Источник: копия действующего файла `~/private/numerologia-daily-08-msk-21-10-2026.php` с REG.RU, полученная 2026-11-06. Две присланные копии полностью совпали, PHP lint пройден.

**Это сохранение исходника, НЕ публикация.** Рабочие CRON, серверные PHP и подписчики не изменялись.

## Что работает на сервере
- REG.RU CRON: `php ~/private/numerologia-daily-08-msk-21-10-2026.php --run`, запуск каждые пять минут.
- Отправка фактически начинается с 08:00 МСК; окно повтора до 11:59 МСК.
- Скрипт использует существующие `~/private/db.php`, `~/private/bot-config.php` и таблицу `users`.
- Ни конфигурационные файлы, ни токен, ни данные пользователей не должны попадать в GitHub.
- Для чтения состояния предусмотрен режим `--status`; не запускать `--run` вручную без необходимости, чтобы не инициировать отправку.

## ВАЖНО перед удалением gh-pages
Внутри текущей версии скрипта источники текстов прогнозов (`$bankOrigins`) перечислены в таком порядке:
1. `https://atelier-8k2m7q.vercel.app/`
2. `https://numerologia-online.github.io/numerologia-online/` (резервный источник на GitHub Pages).

Поэтому **до проверки доступности первого источника и/или безопасного переноса резервного источника удалять `gh-pages` нельзя**: его удаление может оборвать загрузку прогнозов при недоступности Vercel.

Перед любыми правками: проверить реально опубликованный файл REG.RU, выполнить резервную копию, проверить новый HTTPS-источник JSON, провести `--check` и `--status` на сервере и только потом отдельно согласовывать изменение ссылок в рабочем файле. Нельзя подменять его автоматически при пуше в `main`.
