# Защита авторских текстов на REG.RU

Этот раздел предназначен для серверной выдачи платных трактовок после подтверждения покупки. Он не меняет действующий сайт и не включает оплату.

Принцип: тексты хранятся вне корня сайта; сервер проверяет пользователя, подтверждённую покупку и точный товар перед выдачей результата. При отсутствии подтверждённого доступа возвращается 403. Публичные копии удаляют только после проверки тестовой версии.
