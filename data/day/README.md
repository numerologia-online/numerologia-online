# Банки «Разбор дня»

Действующая структура (см. `personal-day-feature.js`):

- `general/general-day-01.json` … `general/general-day-22.json`: основной текст прогноза для каждой из 22 энергий;
- `practical/practical-day-01.json` … `practical-day-22.json`: соответствующие советы «Сегодня нужно» и «Сегодня нельзя».

В каждом банке 31 запись. Ключ каждой записи — **строка `"1"` … `"31"`** (персональная позиция `personalNumber`); это **не номер календарного дня**. В файлах встречается историческое поле `calendarDay`, но поиск текста в приложении идёт именно по `personalNumber`.

Энергия `energy` определяет имя пары файлов. Функция `findDayEntry` временно умеет читать старые ключи вида `"1-23"` для совместимости, но новые записи должны использовать `"23"`.

Алгоритм вычисляет `energy` и `personalNumber` отдельно. Он не выбирает тексты случайно. Не менять формулу и трактовку энергий без согласования с методикой.

Важно: данные загружаются браузером с публичного адреса Vercel, даже если исходный GitHub-репозиторий закрыт. Платные тексты нельзя защищать только клиентским кодом.
