# Тексты разбора дня

Структура банка:

- `data/day/personal/energy-01.json` — личная энергия 1
- `data/day/personal/energy-02.json` — личная энергия 2
- …
- `data/day/personal/energy-22.json` — личная энергия 22

Каждый файл содержит:

- `personalEnergy` — личная энергия;
- `entries` — объект связок;
- ключ записи: `личная энергия-календарный день`;
- `generalEnergy` — общая энергия дня;
- `calendarDay` — календарное число 1–31;
- `text` — готовый текст связки.

Пример ключа: `1-23` = личная энергия 1, календарное число 23. Общая энергия в этой записи хранится отдельно в поле `generalEnergy`.

Следующую серию можно добавлять новым файлом по той же схеме, например `energy-02.json`. Существующие тексты и логику сайта при этом менять не нужно.
