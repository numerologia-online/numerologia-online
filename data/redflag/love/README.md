# Мужчина или Red Flag - Любовь и отношения

## Структура ответов

- `../banks/love.json` - список вопросов раздела и ссылки на отдельные файлы ответов.
- `first-step.json` - 264 индивидуальных ответа на вопрос «Пишет ли первым или ждёт первого шага от женщины?».
- Для каждого следующего вопроса - отдельный JSON-файл рядом, подключаемый через поле `textFile` в списке вопросов.
- Большие тексты храним только в JSON, не в JavaScript.

## Расчёт первого вопроса

Ключ: `reduce22(day)-month`, например `23.07.1990` → `5-7`.

- День рождения от 1 до 22 сохраняется без изменений.
- Числа 23-31 сводятся суммированием цифр до диапазона 1-22.
- Месяц рождения используется от 1 до 12 без преобразования.
- Год рождения, личные циклы и текущая дата не влияют на выбор текста этого вопроса.
- У каждого из 22 × 12 сочетаний есть ровно один цельный ответ.
- Ответы не складываются из шаблонных частей.

## Подключение и качество

`redflag-text-bank.js` загружает отдельный JSON-файл при открытии нужного раздела. Для первого вопроса выводится только цельный ответ без дополнительного шаблонного вердикта и подсказки. Остальные вопросы работают по прежнему алгоритму.

Устаревшая база из 1383 вариантов с учётом года сокращена до 264. Неиспользуемые варианты доступны только через историю GitHub. Отдельный черновой проверочный файл удалён, чтобы не перегружать рабочий проект.
