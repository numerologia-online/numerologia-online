# Мужчина или Red Flag - Любовь и отношения

## Структура ответов

- `../banks/love.json` - список вопросов раздела и ссылки на файлы ответов.
- `first-step.json` - 366 индивидуальных ответов на вопрос «Пишет ли первым или ждёт первого шага от женщины?».
- Для каждого следующего вопроса отдельный JSON-файл, подключаемый через поле `textFile`.
- Большие тексты храним в JSON, не в JavaScript.

## Выбор ответа на первый вопрос

Ключ `day-month`: точный день и месяц рождения, например `23.07.1990` → `23-7`, `05.07.1990` → `5-7`.

- Все календарные даты имеют отдельные тексты: 365 обычных дат и 29 февраля, всего 366.
- Год рождения и личные циклы не влияют на выбор текста.
- Это изменение касается только выбора готовой трактовки, а не расчётов нумерологического профиля.
- Прежние 264 текста оставлены без изменения. Добавлены 102 новых текста для 23-31 чисел месяцев (с учётом длины месяца).
- Каждый ответ представляет собой один связный абзац без склеивания шаблонных частей.

## Подключение

`redflag-text-bank.js` поддерживает `day-month` для этого вопроса и прежний ключ `reduce22(day)-month` для других банков. Остальные вопросы, расчёты и разделы сайта не изменены.
