# Red Flag: деньги и щедрость

## Единый стандарт (цель для всех 80 вопросов)

Один вопрос = один отдельный файл JSON, один ответ на точные день и месяц рождения,
без учёта года и без сворачивания дня к 22 энергиям при выборе текста.
365 обычных календарных дат + 29 февраля = 366 отдельных ключей `day-month`.
Сочетания должны иметь 366 непустых и неповторяющихся авторских трактовок.
При открытии вопроса загружаем только его файл. Все остальные базы не загружаются.

## Существующие файлы

- `../banks/money-questions.json` - вопросы, названия, подключение файлов.
- `gift.json` - «Дарит без повода?». Миграция завершена 19 октября 2026 года:
  366 различных авторских трактовок по точным календарным датам, включая 29 февраля.
  Все первоначальные 264 текста сохранены, дополнены 102 трактовками.
  `keyRule` = `day-month`, `status` = `ready`. Вопрос включён в каталоге,
  версия пути обновлена для сброса старого кэша. Специально добавлена дата 31 октября.
- `generosity.json`, `provider.json`, `courtship.json`, `words-or-deeds.json` -
  уже по 366 ответов и с правилом `day-month`.

## Гарантии

- Не заменять индивидуальные тексты генерацией из трёх-четырёх шаблонов.
- Не считать «готовым» вопрос с пропущенной датой.
- Не менять старые согласованные трактовки при добавлении новых.
- Проверка в GitHub: `tests/redflag-calendar-coverage.test.mjs`.
- История и статистика покупок не требуют хранения результатов расчётов.
