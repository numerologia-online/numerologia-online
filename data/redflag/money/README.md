# Мужчина или Red Flag - Деньги и щедрость

## Структура
- `../banks/money-questions.json` - перечень вопросов и их статусы.
- Для каждого утверждённого вопроса будет отдельный JSON-файл с ответами.
- Объёмные авторские тексты хранятся только в JSON, не в JavaScript.

## Методика
Ключ ответа: `reduce22(day)-month`. День 23-31 сводится суммой цифр до диапазона 1-22, месяц рождения остаётся от 1 до 12. Год рождения и личные циклы не влияют на выбор.

## Статус
Пока ни один новый текст раздела «Деньги и щедрость» не утверждён. Январские примеры для вопроса о подарках были предложениями на согласование, а не готовыми ответами. Их убрали из действующей версии.

До отдельного явного согласования новые тексты не добавлять. Для всех десяти вопросов пока показывается сообщение о подготовке авторской трактовки.

Старые банки, шаблоны и черновики этого раздела удалены из рабочей ветки. При необходимости прежние версии доступны в истории GitHub.
