Файл для Telegram-бота

Вставь действующий токен из BotFather, затем нажми синюю кнопку. Ничего переписывать вручную не нужно.

🔒 Токен остаётся на твоём устройстве. Страница не отправляет его в интернет и не содержит внешних скриптов. Создаётся только файл для загрузки в приватную папку REG.RU.

Для этой кнопки открой страницу в Safari по ссылке на нашем сайте.

Готовый файл сохрани в загрузках iPhone. Его нужно будет положить только в /private/ на REG.RU, не в /www/.

Этот файл будет содержать секретный ключ. Не присылай его в переписку и не загружай в GitHub.
