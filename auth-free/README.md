# Бесплатный Telegram OAuth на PHP (подготовка, НЕ подключено к живому сайту)

Этот каталог подготовлен как лёгкий backend для отдельного бесплатного хостинга, например Free Sprinthost. GitHub Pages не выполняет PHP. **Бесплатная поддержка исходящих HTTPS-запросов к Telegram должна быть проверена на самом хостинге до переключения рабочего входа.**

**Никаких секретов в репозитории.** Исходники можно загрузить в корень технического домена, а в \`lib/config.local.php\` создать закрытый конфиг по примеру \`lib/config.example.php\` непосредственно через панель хостинга. Доступ к папке \`lib/\` блокирует Apache .htaccess. При загрузке проверить, что .htaccess действует.

В конфиге указать:
- \`telegram_client_id\` — публичный ID, уже указан в примере.
- \`telegram_client_secret\` — секрет из BotFather, вводить только непосредственно в панели хостинга.
- \`session_secret\` — независимый случайный секрет от 32 символов.
- \`auth_url\` — HTTPS-адрес технического домена (без конечного /).
- \`site_url\` — адрес главной страницы GitHub Pages.

Затем добавить в BotFather > Login Widget > Redirect URIs точный адрес \`<auth_url>/api/callback.php\`. **Не удалять предыдущие адреса до проверки.**

HTTP GET:
- \`/api/start.php\` — перенаправляет браузер в Telegram (Authorization Code + PKCE, nonce, state).
- \`/api/callback.php\` — проверяет ответ Telegram, подпись JWT и возвращает кратковременный подписанный тикет в URL-фрагменте GitHub Pages.
- \`/api/session.php\` — валидирует тикет и возвращает идентификатор и имя. Нет базы, PDF, расчётов или телефонов.
Тикет истекает через 1 час. Это прототип без постоянного учёта пользователей и без платных прав доступа.

**Статус:** PHP-сервер ещё не развёрнут; основной сайт не переключать до подтверждённого теста по HTTPS. Файл \`auth-profile.js\` на GitHub Pages пока использует старый Telegram popup.

Требуется PHP >= 8.0, расширения cURL, OpenSSL, mbstring, исходящие HTTPS-запросы на \`oauth.telegram.org:443\`, Apache .htaccess. В тарифе Free Sprinthost эти функции нужно проверить, прежде чем обещать реальный вход.
