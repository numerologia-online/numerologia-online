# Профессиональная матрица. Правила и контроль качества

Этот раздел живёт по адресу pro.
Расчёты выполняет numerology-core.js. Интерфейс подключён через pro/pro.js.
Авторские большие расшифровки энергий находятся в knowledge/full-report/sections.
Исходные тексты энергий не требуется переписывать при улучшении кармических программ.

## Расчёты

Используем 22 энергии. Числа от 1 до 22 не сводятся. Суммы больше 22 уменьшаются сложением цифр.
Базовые позиции. День рождения. Месяц рождения. Сумма цифр года. Нижняя точка. Центр.
Родовые диагонали рассчитываются через собственную центральную точку родового квадрата.
Денежный канал и любовь рассчитываются в нижнем правом секторе.
Проверяйте порядок и место каждой тройки до её толкования.

## Кармический хвост

Хвост записываем в порядке от внутренней точки к нижней вершине. Сначала сумма нижней точки и центра. Затем сумма первой энергии и нижней точки. Затем нижняя точка.
В этом порядке существует 26 комбинаций для календарных дат с 1900 по 2026 год.
Тройки 9-9-18 и 18-9-9 и 9-18-9 отличаются. Их тексты должны оставаться разными.
Трактовки хвостов находятся в karmic-tails.md.
Практические дополнения для хвостов находятся в pro/karmic-tail-deepening-a.json и pro/karmic-tail-deepening-b.json.

## Остальные программы

Для поискового каталога используем десять последовательностей по линиям матрицы.
Ведущие числа и смысл зависят от расположения программы.
Кармический хвост и материальная карма не тождественны талантам родовым линиям или отношениям.
Не присваивайте тяжёлые кармические названия всем совпадениям.
Активный каталог содержит 34 достижимых именованных сочетания.
Девять иных старых вариантов сохранены без удаления в knowledge/archive/karmic-programs-outside-current-formulas.md.
Все десять фактических троек пользователя доступны для просмотра. Неназванные тройки не получают выдуманного названия.

## Тексты

Отдельная программа должна раскрывать возможное прошлое. Современное проявление. Минус. Плюс. Конкретное действие.
В новых трактовках используются только точка и короткий дефис.
Нельзя автоматически приписывать вину за сражение на равных воинам.
Воспитание детей остаётся задачей отдельной детской матрицы.
Каждую трактовку нужно проверять по обычным ситуациям жизни. Работа. Деньги. Отношения. Дом. Собственный выбор.

## Публикация

Рабочая ветка main. Не создавать новую ветку без прямого запроса владельца.
Основной раздел для проверки через Vercel.
GitHub Pages не используется как ссылка для проверки закрытого репозитория.
Новая версия должна иметь опубликованный Production deployment именно последнего main коммита.
