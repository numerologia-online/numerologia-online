# Классическая школа нумерологии: фиксированные правила и источники

Версия: 12.10.2026. Эта школа работает независимо от Матрицы судьбы (22 энергии) и от будущей школы «Квадрат Пифагора».

## Выбранный метод
1. **Основные числа**: 1-9 и отдельно мастер-числа 11, 22, 33. Для этих чисел при приведении сохраняются 11/22/33. Число 15 сводится к 6, а НЕ остаётся 15, как в Матрице судьбы.
2. **Число жизненного пути**: отдельно привести месяц, день, сумму цифр года; затем сложить три результата и привести снова с сохранением мастер-чисел. Это зафиксированный вариант, а не метод одной большой суммы по всей дате. Проверка: 14.07.1990 = 7+5+1=13→4; 11.11.2009 = 11+11+11 = 33.
3. **Число дня рождения**: сохраняем исходный день 1-31; отдельно отмечаем корневое число (например, 29/11).
4. **Личный год, месяц, день**: календарная схема; цикл от 1 до 9, без сохранения мастер-чисел. Личный год = корень(месяц рождения + день рождения + цифры календарного года); месяц = корень(личный год + номер месяца); день = корень(личный месяц + номер дня). Есть школы с отсчётом от дня рождения - здесь они не смешиваются.
5. **Расчёт имени**: число выражения = все буквы; число сердца = гласные; число личности = остальные. Для латиницы используется последовательная таблица A=1...I=9, J=1; Y пока отнесена к согласным, и это явно сказано ученику.
6. **Кириллица**: современная адаптация по порядку 33 букв, с отдельной Ё: А=1, Б=2, ... Ё=7, ... Я=6. Нет единого общепринятого международного канона для русских букв. Использовать одну таблицу в пределах всей школы и отдельно помечать языковую адаптацию. Нельзя незаметно транслитерировать смешанные имена.
7. **Конфиденциальность**: расчёт имени и даты выполняется в браузере; ФИО в программу школы не отправляется (нет сервера для пользовательских данных). Сохраняется локально только список пройденных уроков.

## Программа (12 коротких уроков)
- 01 Девять чисел 1-9
- 02 Приведение чисел
- 03 Мастер-числа 11/22/33
- 04 Число жизненного пути
- 05 Число дня рождения
- 06 Таблица букв
- 07 Число выражения
- 08 Число сердца
- 09 Число личности
- 10 Личный год
- 11 Личный месяц и день
- 12 Первый полный учебный разбор

Материалы разбиты на JSON-файлы по одному на урок. Карточки чисел и схемы создаются средствами CSS и встроенного SVG, без библиотек графики, фотографий или внешнего CDN.
